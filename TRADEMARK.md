# HandZoo™ Trademark Guidelines

This document outlines the policy regarding the use of trademarks associated with the HandZoo project. 

While the source code of HandZoo is made available under an open-source license, that license applies strictly to the source code (copyright). It does not grant any rights or licenses to use the project's brand identity, names, logos, or slogans.

## Our Trademarks
The HandZoo project claims common law trademark rights in the United States and other jurisdictions for:
* **HandZoo™** (The project name)
* **"let there be text"™** (The project slogan)
* The official HandZoo logo (including any SVG variants depicting structured LaTeX, cascading exponents, or subscripts).

## Permitted Use
You may use the name "HandZoo" without prior written permission under the following conditions:
* **Truthful Description:** You may refer to the HandZoo project to truthfully describe the software, its features, or compatibility (e.g., "This tool is a plugin for HandZoo" or "Based on HandZoo source code").
* **Attribution:** You may keep original authorship references as required by the project's open-source license.

## Prohibited Use
You may not use the HandZoo trademarks in the following ways without explicit written consent:
* **Fork Branding:** If you fork this repository or modify the source code, you must change the name of the project, the slogan, and remove the official logos. You cannot distribute a modified version under the name "HandZoo".
* **Implying Endorsement:** You cannot use the name, slogan, or logos on a website, commercial product, package registry (e.g., npm, PyPI), or application store in a way that implies the project owners endorse, sponsor, or are affiliated with your work.
* **Confusingly Similar Marks:** You may not use a name, slogan, or logo that is confusingly similar to HandZoo or "let there be text" for a competing text, math, or diagram recognition application.
